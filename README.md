# SMART-CT-MARKS-MANAGEMENT-SYSTEM
An efficient web application for accurate CT marks management and student performance analysis.
## Project Overview

:-Smart CT Marks Management System is a web-based application designed to digitize and simplify the process of entering, storing, updating, viewing, and analyzing Class Test (CT) marks.

:-In the traditional system, teachers may maintain marks using registers, Excel sheets, or separate files. Managing these records manually can result in data-entry errors, difficulty in searching records, duplicate records, and time-consuming calculations.

:-The proposed system provides a centralized platform where authorized teachers can enter and manage CT marks, while students can securely view their own marks and performance.
## Problem Statement:-
Existing Problem In many educational institutions, CT marks are maintained manually or using separate spreadsheets.
This creates several problems:

:-Manual entry requires significant time.

:-Marks can be entered incorrectly.

:-Searching for a particular student's marks is difficult.

:-Updating incorrect marks can be inconvenient.

:-Calculations such as average and percentage have to be performed manually.

:-Maintaining records for multiple classes and subjects becomes difficult.

:-Students may not have immediate access to their CT marks.

:-There is limited visualization of a student's performance across multiple CTs.

:-Maintaining historical records becomes difficult.

:-There is no centralized and role-based system for managing CT records.

## Main Objectives
The major objectives of the project are:

Objective 1 — Digitization

:-To replace manual CT marks management with a digital system.

Objective 2 — Reduce Errors

:-To minimize calculation and data-entry errors through validation.

Objective 3 — Save Time

:-To reduce the time required by faculty for entering and managing marks.

Objective 4 — Centralized Storage

:-To store all CT-related information in an organized database.

Objective 5 — Easy Access

:-To allow authorized users to access relevant academic information easily.

Objective 6 — Performance Tracking

:-To provide students and teachers with a clear view of CT performance.

Objective 7 — Secure Access

:-To provide role-based access so users can access only the information relevant to their role.
